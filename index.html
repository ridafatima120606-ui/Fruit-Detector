🍎 Fruit Detector

Identify fruits using your webcam or an uploaded picture

About the project

Fruit Detector is an image-classification project made with Google Teachable Machine and TensorFlow.js. Use your webcam for live predictions or upload a fruit picture. The model returns the fruit classes it was trained to recognize.

For webcam use, allow camera permission when your browser asks. Camera access generally requires HTTPS or localhost; GitHub Pages provides HTTPS.
